Getting started with mdview

Read documents and code in your browser.

  1. Double-click mdview-1.0.4-macos-arm64.pkg and complete the installation.
  2. Open mdview from Applications and select a file or folder, or type mdview in Terminal.
  3. The installer registers the CLI automatically for all users on this Mac.

No Go, Homebrew, or Terminal setup is required.

Share a document by opening a Markdown file and choosing Export → Save as Markdown ZIP…. Navigation and state diagrams become Mermaid code, and job flows become PNGs with Markdown image references. Existing Mermaid code is preserved. Extract the ZIP, keep its folder structure, and open document.md in a Markdown viewer that supports Mermaid.

When you finish recording, save it in the browser before clicking Stop Viewer in the app.

Apple Silicon (M1 or later) · macOS 13 or later
An internet connection is required to load document rendering resources.
See the included INSTALL.md for detailed instructions.
