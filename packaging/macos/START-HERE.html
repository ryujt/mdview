Getting Started with mdview

Read documents and code comfortably in your browser.

  1. Double-click mdview-1.0.4-macos-arm64.pkg and complete the installation.
  2. Launch mdview from Applications and choose a file or folder, or type mdview in Terminal.
  3. The CLI path is registered automatically, and other users on this Mac can use it right away.

No Go, Homebrew, or Terminal setup is required.

Sharing documents: Open a Markdown file and click Export → Save as Markdown ZIP…. Navigation and state diagrams are saved as Mermaid code, and job flows as PNGs with Markdown image references. Existing Mermaid code is kept. Extract the ZIP, keep the folder structure, and open document.md in any Markdown viewer that supports Mermaid.

When you've finished recording, save it in the browser first, then click Stop Viewer in the app.

Apple Silicon (M1 or later) · macOS 13 or later
An internet connection is required to load document rendering resources.
