Installs the mdview app and Terminal command

Read documents and code comfortably in your browser.

  • App: /Applications/mdview.app
  • Terminal command: /usr/local/bin/mdview

mdview is installed for all users on this Mac. Administrator authentication may be required.

After installation, launch the app or type mdview in Terminal.
No Go or Homebrew installation or PATH setup is required.

Apple Silicon Mac · macOS 13 or later. Rendering documents requires an internet connection.
