Install the mdview app and Terminal command

Read documents and code in your browser.

  • App /Applications/mdview.app
  • Terminal command /usr/local/bin/mdview

Installation makes mdview available to all users on this Mac. Administrator authentication may be required.

After installation, open the app or type mdview in Terminal.
No Go, Homebrew, or PATH configuration is required.

Apple Silicon Mac · macOS 13 or later. An internet connection is required to render documents.
